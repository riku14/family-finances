## ディレクトリ構成

このアプリはモノレポ構成で開発します。
OpenAPIをしようしたAPIファーストな設計とするため、`Package by Feature` を採用したディレクトリ構成とします。

**全体構成**
```
family-finances/
├── backend/        # Spring Boot
├── frontend/       # Vite + React
├── docker/         # Docker関連設定
├── openapi.yaml    # 共通API契約
├── compose.yaml
├── .mise.toml
└── README.md
```

**フロントエンド**
```
frontend/
├── src/
│   ├── main.tsx                    # エントリポイント
│   ├── App.tsx

│   │   ├── ui/                     # shadcn/ui

│   │   └── common/                 # ConfirmDialog, Loading など
│   │

│   │   │   └── pages/              # ページコンポーネント

│   ├── hooks/                      # アプリ全体で使うフック

│   └── styles/                     # グローバルCSS

├── public/                          # 静的ファイル
├── package.json

```

## Git運用ルール
- baseBranchは `develop` を使用すること
- Branchの命名規則としてプレフィックスを付けて切ること
    - feature：機能追加
    - docs:ドキュメント作成
    - refactor:リファクタリング
    - fix:バグ修正
    - test:テスト実装
