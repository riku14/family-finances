## ディレクトリ構成

このアプリはモノレポ構成で開発します。
OpenAPIをしようしたAPIファーストな設計とするため、`Package by Feature` を採用したディレクトリ構成とします。

**全体構成**
```
family-finances/
├── backend/        # Spring Boot
├── frontend/       # Vite + React
├── docker/         # Docker関連設定
├── openapi.yaml    # 共通API契約
├── compose.yaml
├── .mise.toml
└── README.md
```

**コード生成の仕組み**

`build.gradle` に `org.openapi.generator` プラグインを設定済み。`./gradlew build` 時に自動で実行される。

```
docs/openapi.yaml
       ↓ ./gradlew build（自動）
build/generated/src/main/java/com/example/api/
├── TransactionsApi.java   ← @RequestMapping 付きインターフェース
└── model/TransactionResponse.java  ← DTO

       ↓ 自分で実装
domain/transaction/controller/TransactionController.java
  implements TransactionsApi { ... }
```

`build/` は `.gitignore` に追加すること（Gradle 標準で除外されているが念のため確認）。

## Git運用ルール
- baseBranchは `develop` を使用すること
- Branchの命名規則としてプレフィックスを付けて切ること
    - feature：機能追加
    - docs:ドキュメント作成
    - refactor:リファクタリング
    - fix:バグ修正
    - test:テスト実装
