# プロフィール更新API

## 概要
ログインユーザーのニックネームを更新する。V2でアイコン、画像の追加を想定する。

---

## エンドポイント

```http
PUT /api/users/me
```

---

## リクエスト

### ヘッダー

| 項目 | 値 |
|---|---|
| Content-Type | application/json |
| Authorization | Bearer <accessToken> |

---

### リクエストパラメータ

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| userName | String | ○ | 新しく入力されたニックネーム |

---

### リクエスト例

```json
{
  "userName": "新しいユーザー名"
}
```

---

## レスポンス

### 成功時

#### 200 OK

ユーザーが入力した変更が反映された場合に返す。

---

### レスポンスパラメータ

| パラメータ | 型 | 説明 |
|---|---|---|
| userName | String | 新しいユーザーのニックネーム。画面表示に用いる。 |

---

### レスポンス例

```json
{
  "userName": "新しいユーザー名"
}
```

---

## エラー

### エラーレスポンスパラメータ

| パラメータ | 型 | 説明 |
|---|---|---|
| errorCode | String | エラーコード |
| message | String | エラーメッセージ |

---
### 400 Bad Request

userNameが入力されていなかった場合に返す。

---

### エラーレスポンス例

```json
{
  "errorCode": "BAD_REQUEST",
  "message": "ユーザー名を入力してください。"
}
```

---
### 401 Unauthorized

ユーザーのアクセストークンが一致しなかった場合に返す。

---

### エラーレスポンス例

```json
{
  "errorCode": "UNAUTHORIZED",
  "message": "認証に失敗しました。"
}
```
