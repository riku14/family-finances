# ログアウトAPI

## 概要
現在使用しているトークンを削除し、ログアウトする。

---

## エンドポイント

```http
POST /api/auth/logout
```

---

## リクエスト

### ヘッダー

| 項目 | 値 |
|---|---|
| Content-Type | application/json |
| Authorization | Bearer <accessToken> |

---

### リクエスト例

```json
{}
```

---

## レスポンス

### 成功時

#### 200 OK

ログアウトが完了した場合に返す。

---

### レスポンスパラメータ

| パラメータ | 型 | 説明 |
|---|---|---|
| message | String | ログアウトが完了したことを示すメッセージ |

---

### レスポンス例

```json
{
  "message": "ログアウトしました。"
}
```
